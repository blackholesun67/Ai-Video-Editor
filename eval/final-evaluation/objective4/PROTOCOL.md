## B. Expert Evaluation — ต้องใช้คนจริง

### สถานะ: NOT SET UP (แผนจำนวนคนอัปเดตตามที่ผู้ใช้กำหนด 2026-10-06 — รายละเอียดใน `PARTICIPANT-PLAN.md`)

| หัวข้อ | รายละเอียด |
|---|---|
| Participant requirements | ผู้เชี่ยวชาญด้านการตัดต่อวิดีโอ หรือผู้สอน/ผู้เชี่ยวชาญในสาขาที่เกี่ยวข้องกับเนื้อหาคลิปทดสอบ — **3 ท่าน** (เดิมแนะนำ ≥2 คน) |
| Task | ผู้เชี่ยวชาญแต่ละท่าน **รันระบบเอง** กับ **2 คลิป**: ไฟล์ B1 ด้วยโหมด "เก็บเนื้อหาครบ" และไฟล์ C ด้วยโหมด "สรุปให้เข้าใจครบ" แล้วประเมินผลที่ระบบตัดให้ตามนั้นตาม rubric (รวม 3 × 2 = 6 ชุดแบบประเมิน) — ผลตัดของแต่ละท่านจึงอาจต่างกัน |
| Rubric | ร่างไว้ใน `PARTICIPANT-PLAN.md` (4 มิติ Likert 1–5) — ยังไม่ผ่านการยืนยันจากอาจารย์ที่ปรึกษา |
| Procedure | ร่าง: (1) อัปโหลดไฟล์และเลือกโหมดตามที่กำหนด รอระบบประมวลผล (2) กดเรนเดอร์ตามข้อเสนอของระบบก่อน แล้วดูผลและตอบส่วน ก (3) ลองแก้ช่วงตัด 1 จุดและแก้คำบรรยาย 1 บรรทัด (ไม่เรนเดอร์ซ้ำ) แล้วตอบส่วน ข — ดูข้อติดขัดของขั้น (3) ใน `PARTICIPANT-PLAN.md` ส่วน B |
| Timing | ประมาณ 5–10 นาทีต่อคลิป (ต้องยืนยันจริงตอนนำร่อง/pilot) |
| Evidence | แบบประเมินที่กรอกแล้วต่อผู้เชี่ยวชาญต่อคลิป |
| Metric | **ค่าเฉลี่ย + ช่วงต่ำสุด–สูงสุด** ของคะแนนต่อมิติ (ต่อคลิป), ความเห็นเชิงคุณภาพ — ไม่รายงานค่าความสอดคล้องระหว่างผู้ประเมิน เพราะแต่ละท่านรันระบบเอง ผลตัดที่ประเมินจึงไม่ใช่ชุดเดียวกัน |

**⚠️ ยังไม่ยืนยัน:** (ก) ขั้น "แก้ช่วงตัด 1 จุดหลังเรนเดอร์" ทำไม่ได้ในหน้าเว็บปัจจุบัน (ไม่มีทางย้อนกลับไปหน้าเลือกช่วง) — ทางเลือกอยู่ใน `PARTICIPANT-PLAN.md` ส่วน B (ข) ไฟล์ B1 และ C ยังไม่อยู่ใน repo (ผู้ใช้ระบุเพียงชื่อ) — ยังไม่ได้ตรวจความยาว/ขนาด ; ถ้าเข้าผ่านโดเมน Cloudflare ไฟล์ต้องไม่เกิน 100 MB

**สิ่งที่ต้องเตรียม:** ยืนยัน rubric, หาผู้เชี่ยวชาญ 3 ท่าน, เตรียมไฟล์ B1 และ C, ให้ผู้เชี่ยวชาญเข้าถึงระบบได้ (ระบบต้องรันอยู่)

## C. User Evaluation — ต้องใช้คนจริง

### สถานะ: NOT SET UP (แผนจำนวนคนอัปเดตตามที่ผู้ใช้กำหนด 2026-10-06)

| หัวข้อ | รายละเอียด |
|---|---|
| Participant requirements | ผู้ใช้ทั่วไปที่เป็นกลุ่มเป้าหมายของระบบ (เช่น ผู้ผลิตคอนเทนต์/ครีเอเตอร์) — **10 คน** |
| Task | ให้ผู้ใช้ทดลองใช้ระบบจริงตั้งแต่อัปโหลดจนได้ผลลัพธ์ (ผ่านหน้าเว็บจริง ไม่ใช่ script) |
| Task success | อัปโหลด→preview→แก้ไข→render ได้ครบโดยไม่ต้องมีคนช่วยแทรกแซง (binary + บันทึกจุดที่ติดขัด) |
| Task time | จับเวลาแต่ละขั้น (อัปโหลด, รอประมวลผล, แก้ไข, render) |
| Questionnaire | แบบสอบถามความพึงพอใจ/การรับรู้การควบคุม (perceived control) — ใช้ **SUS (System Usability Scale)** ถ้า Test Plan ฉบับจริงกำหนดไว้ (ยังไม่ยืนยัน) |
| Evidence | บันทึกเวลา, แบบสอบถามที่กรอกแล้ว, บันทึกการสังเกต (ถ้ามี) |
| Metric | task success rate, task time, คะแนนแบบสอบถาม (satisfaction/perceived control/SUS) |

**สิ่งที่ต้องเตรียม:** แบบสอบถามมาตรฐาน (ยืนยัน SUS หรือแบบอื่น), หาผู้เข้าร่วม 10 คน, เตรียมสภาพแวดล้อมทดสอบ (ระบบต้องรันอยู่ ผู้ใช้ทดสอบเป็นคนสั่งเอง)

## D. Manual vs AI-assisted — ต้องใช้คนจริงทั้งสองฝั่ง

### สถานะ: NOT SET UP (แผนอัปเดตตามที่ผู้ใช้กำหนด 2026-10-06: เพื่อน 4 คน แบบ 2×2)

| หัวข้อ | รายละเอียด |
|---|---|
| Task | ให้ผู้เข้าร่วมตัดคลิปโจทย์เดียวกัน 2 แบบ: (1) ตัดเองล้วน ๆ ด้วยโปรแกรมตัดต่อทั่วไป (2) ใช้ระบบนี้ช่วย แล้วปรับแต่งต่อ ; งานที่ต้องการ "ไม่ตัดอะไร" (งาน A ของ 4D, และงาน CER/WER) ใช้ โหมด "เก็บเนื้อหาครบ" + กดปุ่ม "เลือกทั้งหมด" ในหน้า preview (ไม่มีโหมดแยกสำหรับ "ไม่ตัดอะไร" — ระบบยังวิเคราะห์ตามปกติ แล้วปุ่มนี้ติ๊กเก็บทุกช่วงรวมช่วงที่ AI เสนอตัด) |
| Participant requirements | **เพื่อน 4 คน** · within-subject (แต่ละคนทำทั้ง 2 วิธี คนละคลิป) |
| Design (2×2) | วิธี (manual / AI-assisted) × คลิป (A / B) สลับลำดับและการจับคู่วิธี–คลิป ให้ครบ 4 รูปแบบ รูปแบบละ 1 คน — ตารางอยู่ใน `PARTICIPANT-PLAN.md` ส่วน D |
| Procedure | ร่าง: (1) อธิบายงาน (2) รอบที่ 1 จับเวลา (3) รอบที่ 2 จับเวลา (4) เก็บผลลัพธ์ทั้งสองแบบ (5) แบบสอบถามเปรียบเทียบ |
| Timing | จับเวลารวมของแต่ละแบบ |
| Questionnaire | เปรียบเทียบ perceived control / satisfaction ระหว่าง 2 แบบ |
| Evidence | ไฟล์ output ทั้ง 2 แบบต่อผู้เข้าร่วม, เวลาที่ใช้, แบบสอบถาม |
| Metric | task time (manual vs AI-assisted), task success, satisfaction เปรียบเทียบ — **ห้ามใช้ Claude ตัดสินว่าแบบไหน "ดีกว่า"** ต้องเป็นการประเมินของผู้เข้าร่วมเองหรือผู้เชี่ยวชาญ (ส่วน B) เท่านั้น |

**⚠️ ยังไม่ยืนยัน:** ตีความ "2×2" ว่าเป็นตาราง วิธี × คลิป (crossover) ตามข้างบน ; คลิป A/B ยังไม่ระบุ ; n = 4 → รายงานเป็นรายบุคคล/เชิงพรรณนา ไม่ทำสถิติอนุมาน

**สิ่งที่ต้องเตรียม:** หาเพื่อน 4 คน, เตรียมโปรแกรมตัดต่อสำหรับฝั่ง manual, เตรียมคลิป A/B ที่ยากง่ายใกล้เคียงกัน

## สรุปการแยกงาน

| ส่วน | ใครทำ | พร้อมแค่ไหน |
|---|---|---|
| A. Functional | Claude/script | เตรียมได้ทันที ไม่ต้องรอคน |
| B. Expert evaluation | คนจริง (ผู้เชี่ยวชาญ) | ต้องออกแบบ rubric + หาคนก่อน |
| C. User evaluation | คนจริง (ผู้ใช้ทั่วไป) | ต้องออกแบบ questionnaire + หาคนก่อน |
| D. Manual vs AI-assisted | คนจริงทั้งสองฝั่ง | ต้องออกแบบ procedure + หาคนก่อน |

**Claude ไม่ควรทำ B/C/D แทนคนไม่ว่าในรูปแบบใด** (รวมถึงการ "จำลอง" ความเห็นผู้ใช้หรือให้คะแนนแทน) — เป็นหลักการที่ผู้ใช้กำชับไว้ตั้งแต่รอบ Pre-Final Audit และย้ำอีกครั้งในรอบนี้
