## A. หน้า Preview (เมื่อประมวลผลเสร็จ)

1. [ ] เห็นหัวข้อ "เลือกช่วงที่จะ**เก็บไว้**" ไม่ค้างที่ "กำลังโหลดตัวอย่าง..." เกิน ~5 วินาที
2. [ ] มีแท็บกรอง **ทั้งหมด / AI เลือก / AI ตัดออก** — กดแต่ละแท็บแล้วรายการเปลี่ยน (AI ตัดออก = ควรเห็นช่วง ~46.5–54 และ ~67.6–73.9)
3. [ ] แถบไทม์ไลน์: **ปูเต็มตั้งแต่ต้นจนท้ายคลิป ไม่มีช่องว่าง/ทับกัน** (CLAUDE.md §2.4) ; ช่วงที่ AI ตัดออกเห็นต่างสีจากช่วงที่เก็บ
4. [ ] ตัวเลขสรุปบนปุ่มล่าง "ถัดไป — แก้ subtitle (N ช่วง · ความยาว)" ตรงกับที่ติ๊กอยู่ (คาด 3 ช่วง · ~2:09.7)
5. [ ] กดปุ่ม **"เล่นเฉพาะช่วงนี้"** (ไอคอนเล่นที่แถว) ของช่วงที่ 2 → วิดีโอเล่นตรงช่วงนั้นจริง (ดูเวลาบนตัวเล่น ~54.0 วินาที) และเป็น **คลิปต้นฉบับ** ไม่ใช่คลิปที่ตัดแล้ว (CLAUDE.md §2.3)
6. [ ] คลิกบนไทม์ไลน์ → วิดีโอเลื่อนไปตำแหน่งนั้น (ทูลทิป "คลิกเพื่อเลื่อนวิดีโอไปตรงนั้น")
7. [ ] คลิปนี้ไม่มีฉากเปลี่ยน — ปุ่ม "ฉาก" ‹ › ไม่ทำให้พังเมื่อกด (ถ้าปุ่มถูกปิดใช้งานก็ถือว่าปกติ)

## B. ติ๊ก/ยกเลิก และแก้ช่วง

8. [ ] **เอาช่วงกลับมา:** ที่แท็บ "AI ตัดออก" ติ๊กช่วง 46.5–54 (ป้าย "AI ตัดออก" → กลายเป็น "เพิ่มเอง") → ตัวเลขล่างเพิ่มเป็น ~2:17 และจำนวนช่วงเปลี่ยนตามที่ควร (อาจรวมเป็นช่วงติดกัน — ดู `toRenderSegments` merge แถวที่ติดกัน)
9. [ ] **ยกเลิกช่วง:** ยกเลิกติ๊กช่วงที่ 2 → ตัวเลขล่างลดลงตรงกับความยาวช่วงนั้น
10. [ ] **ขยับขอบ:** กดปุ่มปรับเวลา (ไอคอนปรับหัว-ท้าย) ที่ช่วงใดช่วงหนึ่ง กด "เริ่ม" +1 วิ → ป้าย "**ปรับเวลาแล้ว**" ขึ้น ; ตัวเลขความยาวเปลี่ยน 1 วิ ; **ช่วงข้างเคียงขยับตาม ไม่เกิดช่องว่าง** (CLAUDE.md §2.4)
11. [ ] **แยกช่วง:** เลื่อนวิดีโอไปกลางช่วงยาว (~1:30) กดปุ่ม **แยกช่วง** บนแถบไทม์ไลน์ → แถวเพิ่มเป็น 2 ; **ตัวเลขรวมความยาวด้านล่างต้องไม่เปลี่ยน** (splitAt ห้ามเปลี่ยนผลที่ render)
12. [ ] **รวมช่วง:** กดไอคอน "รวมกับช่วงถัดไป (ยกเลิกการแยก)" ของแถวที่เพิ่งแยก → กลับเป็นแถวเดียว ความยาวรวมเท่าเดิม
13. [ ] **คืนค่า AI:** ปุ่ม "คืนค่า AI" กดครั้งแรกเปลี่ยนเป็น "ยืนยัน?" → กดอีกครั้ง → ทุกอย่างกลับเป็นข้อเสนอเดิมของ AI (3 ช่วง, ตัวเลขเดิม) ; ปุ่มนี้ควร**หายไปเมื่อไม่ได้แก้อะไร**
14. [ ] **กันงานหาย:** ทำข้อ 8 ค้างไว้ แล้ว **รีเฟรชหน้า (F5)** → การติ๊ก/แก้ที่ทำไว้ยังอยู่ (กู้จาก localStorage) — ถ้าหายให้จด
15. [ ] กด "ล้าง" (ถ้ามีในหน้า) แล้วไม่ติ๊กอะไรเลย กด "ถัดไป" → ต้องขึ้นข้อความ "กรุณาเลือกอย่างน้อย 1 ช่วง" ไม่ crash

## D. หน้าแก้ซับ ("ตรวจและแก้คำบรรยายก่อนตัดต่อ")

16. [ ] กด "ถัดไป — แก้ subtitle" ไปหน้าแก้ซับได้ ไม่ค้างที่ "กำลังโหลดคำบรรยาย..."
17. [ ] **จำนวนช่วง/ความยาวที่หน้านี้แสดง ตรงกับที่จดในข้อ C** (CLAUDE.md §5 — ห้ามโชว์เลขขัดกันสองหน้า) ; ช่อง "จำนวนบรรทัด" และ "ความยาวที่จะได้" มีค่า
18. [ ] **ซับตรงกับ selection:** ทดสอบเพิ่ม — กลับไปหน้าเลือกช่วง (ปุ่ม "กลับไปเลือกช่วง") ยกเลิกติ๊กช่วง 0:00–0:46.6 ทั้งช่วง แล้วกลับมาหน้าแก้ซับอีกครั้ง → **จำนวนบรรทัดต้องลดลงมาก** (ไม่ใช่ซับทั้งคลิป — บั๊กเดิมของ CLAUDE.md §2.5) ; แล้วกลับไปคืนค่า AI
19. [ ] กดที่บรรทัดซับ/ปุ่ม "ดู" → เพลเยอร์เลื่อนไปตรงเวลาต้นฉบับของบรรทัดนั้น (เพลเยอร์เล่น**คลิปต้นฉบับเต็ม** ตามข้อความบนหน้าจอ)
20. [ ] **แก้ข้อความ:** แก้ซับ 2 บรรทัด (เช่น เติม "[ทดสอบ1]" "[ทดสอบ2]") → ตัวนับ "แก้ไปแล้ว" = 2 และปุ่มล่างเปลี่ยนเป็น "บันทึก (แก้ 2 บรรทัด)"
21. [ ] แก้แล้วยัง**คืนต้นฉบับได้** (ปุ่มคืนคำบรรยาย → ขึ้นกล่องยืนยัน "คืนคำบรรยายกลับเป็นต้นฉบับ?") — กดยกเลิกไว้ก่อน เพื่อคงข้อ 20
22. [ ] (ตัวเลือก) แก้เวลาของบรรทัดหนึ่ง แล้วดูว่าบันทึกไม่ error
