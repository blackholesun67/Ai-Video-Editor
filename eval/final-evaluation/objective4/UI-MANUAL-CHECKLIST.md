## A. หน้า Preview ("เลือกช่วงที่จะเก็บไว้")
1. [ ] ระหว่างรอ เห็นหน้าประมวลผล 4 ขั้น (แยกเสียง → ฟังเสียงพูด → AI คิดวิเคราะห์ → ตัดและรวมคลิป) แล้วเปิดหน้า Preview ได้ ไม่ค้างที่ "กำลังโหลดตัวอย่าง..."

## B. ติ๊ก/ยกเลิก/แยก/รวม/ขยับขอบ
8. [ ] แท็บ "AI ตัดออก" → **คลิกที่แถว** ช่วง 46.5–54 (ไอคอน ✗ → ✓, ป้ายเปลี่ยนเป็น "เพิ่มเอง") → ตัวเลขสรุปเพิ่มขึ้น
9. [ ] คลิกแถวช่วงที่ 2 เพื่อยกเลิก (✓ → ✗) → ตัวเลขลดลงเท่าความยาวช่วงนั้น
10. [ ] กดไอคอนปรับ (แถบเลื่อน) "ปรับเวลาหัว-ท้ายช่วงนี้" → เลือก "ก้าวละ 1 วิ" → กด **เริ่ม +1 วิ** → ป้าย "ปรับเวลาแล้ว" ขึ้น ตัวเลขความยาวเปลี่ยน ~1 วิ และช่วงข้างเคียงขยับตาม ไม่เกิดช่องว่าง
11. [ ] เลื่อนวิดีโอไปกลางช่วงยาว (~1:30) กดปุ่ม **"แยกตรงนี้"** (ไอคอนกรรไกร ใต้แถบไทม์ไลน์) → แถวเพิ่มเป็น 2 (มีป้าย "แก้ช่วงเอง") **ความยาวรวมต้องไม่เปลี่ยน**
12. [ ] ที่แถวที่เพิ่งแยก กดไอคอนหมุนย้อน "รวมกับช่วงถัดไป (ยกเลิกการแยก)" → กลับเป็นแถวเดียว ความยาวรวมเท่าเดิม
13. [ ] ปุ่ม **"คืนค่า AI"** (จางลงถ้ายังไม่ได้แก้) กดครั้งแรกเปลี่ยนเป็น "ยืนยัน?" กดอีกครั้ง → กลับเป็นข้อเสนอเดิมของ AI
14. [ ] ทำข้อ 8 ค้างไว้ แล้วกด **F5 รีเฟรช** → สิ่งที่ติ๊กไว้ยังอยู่
15. [ ] กดปุ่ม **"ล้าง"** (ไม่ติ๊กอะไรเลย) → ปุ่มใหญ่ล่างต้องเป็นสีเทา กดไม่ได้ ไม่ crash ; แล้วกด "คืนค่า AI"

## D. หน้าแก้ซับ ("ตรวจและแก้คำบรรยายก่อนตัดต่อ")
16. [ ] กด "ถัดไป — แก้ subtitle" ไปหน้าแก้ซับได้ ไม่ค้างที่ "กำลังโหลดคำบรรยาย..."
17. [ ] "ความยาวที่จะได้" ตรงกับความยาวที่จดในข้อ C (หน้านี้ไม่แสดงจำนวนช่วง — ออกแบบไว้อย่างนั้น) และมี "จำนวนบรรทัด"
18. [ ] กด "← กลับไปเลือกช่วง" → ยกเลิกช่วง 0:00–0:46.6 → กลับมาหน้าแก้ซับ → "จำนวนบรรทัด" **ต้องลดลงมาก** (ไม่ใช่ซับทั้งคลิป) ; แล้วกลับไป "คืนค่า AI"
19. [ ] กดปุ่ม **"ดู"** ที่บรรทัดซับ → วิดีโอ (ต้นฉบับเต็ม) เล่นตรงเวลาของบรรทัดนั้น
20. [ ] แก้ข้อความ 2 บรรทัด (พิมพ์ต่อท้าย "[ทดสอบ1]" "[ทดสอบ2]") → ป้าย "แก้แล้ว" ขึ้น, "แก้ไปแล้ว" = 2, ปุ่มล่าง "บันทึก (แก้ 2 บรรทัด)"
21. [ ] ปุ่ม **"คืนค่าทั้งหมด"** → มีกล่องถามยืนยัน — กด **ยกเลิก** ไว้ก่อนเพื่อคงข้อ 20 (ตัวเลือก: ลองกดตกลงแล้วแก้ใหม่)
