**คู่มือทดสอบระบบทดสอบเเล้ว (UI) — AI Video Smart Editor**

*สำหรับเพื่อนร่วมโปรเจกต์ที่ช่วยทดสอบก่อนปล่อยให้กลุ่มผู้ใช้จริงลอง*

**ทำไมต้องให้เพื่อนช่วยทดสอบตรงนี้**

ระบบผ่านการทดสอบฝั่ง API แล้ว (อัปโหลด → ประมวลผล → AI ตัดสินใจ → เรนเดอร์) แต่ส่วนหน้าเว็บ (ปุ่มต่างๆ ที่ผู้ใช้จะกดจริง) ยังไม่เคยมีใครทดสอบด้วยมือเลย ก่อนจะเปิดให้ผู้ใช้ทั่วไป 10 คนมาทดสอบจริง อยากให้มีคนช่วยไล่เช็คก่อนสักรอบ เพื่อจับบั๊กที่อาจพลาดไป

*หมายเหตุ: ผลการทดสอบนี้นับเป็นการตรวจสอบภายใน (internal QA) ไม่ได้นับรวมเป็นข้อมูลของกลุ่มผู้ใช้ทดสอบอย่างเป็นทางการ เพราะเป็นคนในทีมที่รู้จักระบบอยู่แล้ว*

**ก่อนเริ่ม — เตรียมเครื่อง**

- ขอไฟล์ .env จากเจ้าของโปรเจกต์แยกต่างหาก (ไม่มีอยู่ใน git) ผ่านช่องทางส่วนตัว ไม่โพสต์ในที่สาธารณะ
- Clone โปรเจกต์และ checkout ไปที่ commit ล่าสุดตามที่เจ้าของโปรเจกต์ระบุ (ดูไฟล์ SETUP-FOR-TEAMMATE.md)
- ถ้า login ผ่าน Google แล้วขึ้น error ว่าบัญชีไม่ได้รับอนุญาต ให้แจ้งเจ้าของโปรเจกต์ เพราะอาจต้องเพิ่มอีเมลเป็น Test User ใน Google Cloud Console ก่อน
- ไฟล์ทดสอบ: วิดีโอ V04 (ยาว 2:24) — ขอไฟล์จากเจ้าของโปรเจกต์

**ก่อนเริ่ม — ตั้งค่าครั้งแรกในหน้าเว็บ**

- เปิดเว็บที่ http://localhost แล้วล็อกอินด้วย Google
- หน้าอัปโหลด: ลากไฟล์ V04 ลง — โหมด "เก็บเนื้อหาครบ" และ "แนวนอน 16:9" เป็นค่าเริ่มต้นอยู่แล้ว ไม่ต้องเปลี่ยน
- ติ๊ก "ดูตัวอย่างก่อนตัดจริง" — ถ้าไม่ติ๊กจะไม่ได้เห็นหน้า Preview เลย
- ติ๊ก "ใส่คำบรรยาย (ซับ) ให้อัตโนมัติ" — ถ้าไม่ติ๊กจะไม่มีหน้าแก้ซับเลย
- กด "เริ่มตัดต่อ"
- เปิด DevTools (กด F12) แล้วเปิดแท็บ Console และ Network ค้างไว้ตลอดการทดสอบ

*ค่าที่คาดไว้: AI น่าจะเสนอเก็บ 3 ช่วง คือ 0:00–0:46.6, 0:54.0–1:07.7, 1:13.9–2:23.2 — ถ้าได้ผลต่างจากนี้ ให้จดตัวเลขจริงที่เห็นไว้ (ไม่ผิดปกติเสมอไป แค่ต้องบันทึกไว้)*

## A. หน้า Preview ("เลือกช่วงที่จะเก็บไว้")

**1. รอประมวลผลแล้วเปิดหน้า Preview** → `#ผลลัพท์ทดสอบ: ระบบหน้าประมวณผลทำงาน ต่อเนื่องไม่ค้าง`

**2. แท็บกรอง** → `#ผลลัพท์ทดสอบ: ทั้งหมด 4 เเละตัด2 ช่วง กลาง1:16.1–1:19.2 เเละตัดช่วงท้ายคลิปที่มีเสียงเงียบ 2:23.3–2:24.4 ยาว 1.1 วิ`

**3. แถบไทม์ไลน์ปูเต็ม** → `#ผลลัพท์ทดสอบ: เเถบสีทึบช่วงที่เก็บเต็มต่อเนื่อง เเทบสีขาวช่วงที่ ai ตัดตรง เรียงต่อกันสนิทตั้งแต่ต้นจนท้าย ต่อเนื่อง`

**4. ตัวเลขสรุปตรงกัน** → `#ผลลัพท์ทดสอบ: ปุ่มใหญ่ "2 ช่วง เเก้ subtitle ช่วง 2:19.9 นาที นาที`

**5. ปุ่มเล่นเฉพาะช่วง** → `#ผลลัพท์ทดสอบ: กดเล่นเฉพาะช่วงที่2 วิดีโอด้านบนกระโดดไปเล่นจากช่วงนั้น`

**6. คลิกไทม์ไลน์เพื่อเลื่อนวิดีโอ** → `#ผลลัพท์ทดสอบ: วิดีโอเลื่อนไปที่ตำแหน่งที่เลือกไทม์ไลน์นั้น`

**7. ปุ่มข้ามฉาก** → `#ผลลัพท์ทดสอบ: ไม่เห็นปุ่ม ‹ ฉาก ›` (ตรงตามที่คาด — คลิปนี้ไม่มีฉากเปลี่ยน)

## B. ติ๊ก / แยก / รวม / ขยับขอบ / คืนค่า AI

**8. เอาช่วงที่ AI ตัดกลับมา** → `#ผลลัพท์ทดสอบ: ติ้ก✓ ไอคอนหน้าแถวเปลี่ยนจาก ✓ เป็น ✗ ป้ายเปลี่ยนจากที่ AI ตัดออก`
⚠️ *ข้อความนี้เขียนทิศทางกลับด้าน (checklist คาดว่า ✗→✓ ไม่ใช่ ✓→✗) และประโยคขาดคำต่อท้าย
("ป้ายเปลี่ยนจากที่ AI ตัดออก" ไม่มี "เป็น...") — น่าจะเป็นการพิมพ์สลับ/พิมพ์ไม่ครบมากกว่าอาการจริงของ UI
ตรวจซ้ำกับผลข้อถัดไปแล้วไม่ขัดแย้งกัน จึงไม่ถือเป็น FAIL ตามที่ผู้ทดสอบสรุปเอง แต่บันทึกความคลุมเครือนี้ไว้
ตรง ๆ เพราะยืนยันทิศทางจริงไม่ได้จากข้อความที่ได้มา*

**9. ยกเลิกช่วงที่เก็บ** → `#ผลลัพท์ทดสอบ: ยกเลิกช่วงที่เก็บ เห็น ✓ เป็น ✗ แถวจางลง ตัวเลขลดลงเท่าความยาวช่วงนั้น`

**10. ขยับขอบช่วง** → `#ผลลัพท์ทดสอบ: ขึ้นป้าย "ปรับเวลาแล้ว" ตัวเลขความยาวช่วงที่ติดกันขยับตาม ไม่เกิดช่องว่าง 58.5 → 57.5 วิ ปรับเวลาแล้ว`

**11. แยกช่วง** → `#ผลลัพท์ทดสอบ: ช่วงนั้นแตกเป็น 2 → 3 ช่วง ยาวรวมเท่าเดิม 2:19.9`

**12. รวมช่วงกลับ** → `#ผลลัพท์ทดสอบ: รวมกลับ 3 → 2 ช่วง · 2:19.9 กลับเป็นแถวเดียว ความยาวรวมเท่าเดิม`

**13. คืนค่า AI** → `#ผลลัพท์ทดสอบ: ทุกอย่างกลับเป็นข้อเสนอเดิมของ AI กด 2 ครั้ง → 2 ช่วง · 2:19.9 ปุ่มเทา`

**14. กันงานหายเมื่อรีเฟรช** → `#ผลลัพท์ทดสอบ: หลังโหลดใหม่ สิ่งที่ติ๊กไว้ยังอยู่`

**15. ล้างทั้งหมดแล้วกดไปต่อ** → `#ผลลัพท์ทดสอบ: ปุ่ม "ถัดไป" เทา กดไม่ได้`

## C. จดตัวเลขก่อนไปหน้าถัดไป — 2 ช่วง · 2:19.9

## D. หน้าแก้ซับ

**16. เข้าหน้าแก้ซับ** → `#ผลลัพท์ทดสอบ: เปิดหน้าแก้ซับ ไม่ค้างที่ ขึ้นกำลังโหลดคำบรรยาย`

**17. ตัวเลขตรงกับหน้า Preview** → `#ผลลัพท์ทดสอบ: ความยาวตรงกับที่จดในหัวข้อ C`

**18. ซับต้องตามช่วงที่เลือก** → `#ผลลัพท์ทดสอบ: จำนวนบรรทัด ลดลงมาก`

**19. ปุ่ม "ดู" ที่แต่ละบรรทัดซับ** → `#ผลลัพท์ทดสอบ: เวลาตรงกับที่กล่องบรรทัดแสดง`

**20. แก้ข้อความซับ** → `#ผลลัพท์ทดสอบ: กล่องบรรทัดที่แก้ขึ้นขอบเหลืองและป้าย กล่องสถิติขึ้นแก้ไปแล้ว 2`

**21. ปุ่มคืนค่าทั้งหมด** → `#ผลลัพท์ทดสอบ: ปุ่มล้างข้อความที่แก้ทั้งหมด มีปุ่มถาม ยืนยัน`

**22. ช่องข้อความจำกัด 200 ตัวอักษร** → `#ผลลัพท์ทดสอบ: ไม่เห็นข้อความเด้ง เมื่อเกิน 200 ตัวอักษร เเต่ไม่สามารถพิมต่อได้`

## E. Render และผลลัพธ์

**23. ส่งไปตัดต่อ** → `#ผลลัพท์ทดสอบ: ปุ่มขึ้น กำลังส่งไปตัดต่อ ไม่ค้างจบที่หน้า ตัดต่อเสร็จแล้ว`

**24. เล่นวิดีโอผลลัพธ์** → `#ผลลัพท์ทดสอบ: มีภาพและเสียง ไม่กระตุกหรือเงียบโหลด เล่นได้`

**25. ความยาวผลลัพธ์** → `#ผลลัพท์ทดสอบ: ตรงกับ "ความยาวที่จะได้" 139.9s = 2:19.9 เป๊ะ`

**26. ซับที่เบิร์นตรงข้อความที่แก้** → `#ผลลัพท์ทดสอบ: ทดสอบซับเบิร์นที่ 0:01 ซับในวิดีโอตรงเป๊ะ`

**27. ซับหลังรอยตัดตรงกับเสียง (★ สำคัญที่สุด)** → `#ผลลัพท์ทดสอบ: ซับเลื่อนตาม −3.4s เท่ากับที่ภาพเลื่อนตรงกัน ไม่เหลื่อม ซับไม่คลาด ซัปตรง`
*(−3.4s สอดคล้องกับความยาวช่วงที่ถูกตัดออกจริง (~3.4s ตามที่สรุปไว้ในแบบฟอร์ม) — ยืนยันว่า
`remap_edited_phrases()` คำนวณ offset ถูกตามที่ CLAUDE.md §6 อธิบายไว้)*

**28. ดาวน์โหลด** → `#ผลลัพท์ทดสอบ: กดปุ่มดาวน์โหลดวิดีโอได้ไฟล์ .mp4 เปิดเล่นได้`

**29. แก้คำบรรยายซ้ำจากหน้าผลลัพธ์** → `#ผลลัพท์ทดสอบ: กลับไปหน้าเเก้ซับ ข้อความที่แก้ไว้ยังอยู่`

**30. หน้า "งานของฉัน"** → `#ผลลัพท์ทดสอบ: มีภาพปก กดดาวน์โหลดได้`
